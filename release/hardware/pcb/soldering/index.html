摇杆只校准一次
04 / TROUBLESHOOT

故障优先检查

无 3.3 V电源入口

先查 F1、J1 VBUS、U3 方向、 C14-C17 和 U3 输出连锡。

不出现 RPI-RP2MCU / Flash

检查 U1 pin 1、中心散热焊盘、Y1、 U2 pin 1，以及 3.3 V 是否稳定。

一颗灯不亮，后面全不亮LED 链路

从第一颗不亮的 LED 查 pin 1/DIN、DOUT 和四脚虚焊。整串中断通常是这一颗造成的。

触摸一直触发或完全不触发TP5 / TTP223

检查 R10=0 Ω、U6 pin 1、TP5 电极和弹簧/导线接触。

编码器方向相反RE1

先确认使用的是当前 v5.8 固件；编码器方向已在固件中按实板 A/B 落点处理。

DO NOT FIT C25 · D1 · J2

TP5_CONTACT 只在电极式触摸面板需要时选装。 STAB1 是定位板卫星轴， PCB 上只有 NPTH 让位孔，不焊接。
