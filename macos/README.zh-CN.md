# AgentPad Studio 与 Input

[English](README.md) | 简体中文

AgentPad Studio 和 Input 可用于配置同一台 AgentPad13 设备。两者均兼容实验性的
`codex_oai` 固件，无需在应用之间进行配置转换。

## 选择应用

| 任务 | AgentPad Studio 1.3.2+ | Input 1.0.2 |
|---|---|---|
| 编辑键位绑定 | 支持，使用 AgentPad13 的实际 3D 布局 | 支持，使用 Codex Micro 兼容布局 |
| 处理 4–16 层 | 可读取和编辑现有层；导入可能改变层数 | 可在四个基础层之外添加、编辑和删除扩展层 |
| 重命名层 | 显示由 Input 保存的名称 | 可编辑并保存层名称 |
| 设置层指示色 | 支持 | Studio 可读取共享配置中保存的颜色 |
| 设置全局 LED 电源和亮度 | 支持，并验证回读结果 | 这些设置请使用 Studio |
| 导入/导出 Studio 配置 | 支持 | 使用其自己的设备配置格式 |
| 宏、智能动作和编码器/摇杆重映射 | 不支持 | AgentPad13 适配器不支持 |

日常按键和灯光配置请使用 **Studio**。需要添加或重命名层时使用 **Input**，然后返回
Studio，在物理布局中继续编辑。

## 设置设备和应用

1. 按开发板的 BOOTSEL 流程安装实验性的
   [AgentPad13 Codex/Input 固件 v001C](../release/firmware/prebuilt/agentpad13_codex_oai.uf2)。
   此固件支持 4–16 层。
2. 从 [GitHub Releases](https://github.com/wZuck/agentpad13/releases) 下载 Studio。
   解压 macOS Apple Silicon 安装包，退出旧版应用，然后将
   `AgentPad Studio.app` 移到“应用程序”文件夹。Studio 要求 macOS 13 或更高版本。
3. 通过 USB 连接设备。在 Input 中，它会显示为 **Codex Micro**。更新固件时请使用
   上面提到的 AgentPad13 UF2；Input 的原厂设备固件适用于不同的硬件。

Studio 1.3.1 修复了渲染 Input 扩展动作时发生的崩溃。1.3.2 还会读取自定义层名称。
为获得这些修复而更新 Studio 时，不需要清除设备配置，也不需要重新刷写现有的 v001C
固件。

## 使用 AgentPad Studio 配置

1. 点击 **Scan**（`扫描`），选择设备，然后点击 **Connect and Read**
   （`连接并读取`）。读取操作会用设备配置替换本地草稿。
2. 在 **Edit Layer**（`编辑层`）中选择一个层。在 3D 视图中点击 K00–K12，并分配原生
   按键或 Codex 动作。读取设备后，所有已配置的层（包括在 Input 中添加的层）都可用。
3. 设置当前层的 TP5 指示色。黑色会禁用该层的指示。
4. 点击 **Save to Device**（`保存到设备`）。Studio 会等待确认，并通过回读验证键位绑定。
5. 在 **LED Lighting**（`LED 灯光`）下设置全局 LED 电源和亮度，然后点击
   **Apply Lighting**（`应用灯光`）。这些设置与按键编辑分开保存。
6. 使用 **Export**（`导出`）备份键位绑定、指示色和灯光设置。**Import**（`导入`）和
   **Load Factory Bindings**（`载入出厂键位`）会修改草稿；需要保存键位并应用灯光，
   才能写入这些更改。

选择用于编辑的层不会切换设备的当前活动层。请使用 TP5、摇杆或已分配的换层键更改
活动层。在默认摇杆模式下，左/右操作会循环切换已配置的层；进行下一步前请让摇杆
回到中心。

如果保存超时，请重新读取设备以确认实际状态，然后再继续。用设备读取覆盖重要草稿
之前，请先将其导出。

## 使用 Input 配置

1. 连接到 **Codex Micro** 并加载其配置。
2. 编辑现有层，或添加第 5 至第 16 层。四个基础层为 CODEX、FN、NAV 和 MEDIA；
   额外添加的层可以删除。
3. 分配字母、数字、F1–F24、修饰键、导航/媒体键、Codex 动作或受支持的换层键。
   保存后等待 Input 完成验证。
4. 如需重命名层，请在 Input 中编辑名称并保存。在 Studio 中点击 **Read Device**
   （`读取设备`）或重新连接。层选择器、当前层标题和指示设置会显示已保存的名称，
   包括 Unicode 名称。
5. 在设备上切换到新层并测试其按键。继续在 Studio 中配置之前，请打开 Studio 并
   重新读取。

Input 显示的键位排布为 **2/4/4/3**。按显示顺序展开后，这些按键对应 AgentPad13 的
K00–K12；最后一个键是独立的 2U 键。请使用 Studio 的 3D 视图检查实际物理位置。

适配器支持一个设备配置，可包含 4–16 层。宏、智能动作、多配置以及对固定编码器/
摇杆控制的更改都会被拒绝。Input 中的许多多修饰键快捷键使用宏，因此不在当前支持
范围内。Input 在新层中显示为空的控制占位项，会继承设备固定的编码器和摇杆行为。

## 在两个应用之间切换

先在第一个应用中保存，然后在第二个应用中读取或重新连接，再进行编辑。Studio 和
Input 共用设备的键位映射、层名称和指示色；更改可在重启后保留。建议一次只使用一个
应用进行配置：无法保证同时发出的 HID 请求彼此隔离。

构建说明、架构、协议、兼容性证据和验证方法参见[设计与开发](DESIGN.zh-CN.md)。
